# business-model-layers-diagram.png

**Type:** Layered business-role stack illustration, not a UML or
entity-relationship diagram.
**Source context:** `# Introduction` / `## Context or Background`,
illustrating the four-layer wholesale/retail broadband value chain
referenced throughout the use case.

Four stacked boxes, top to bottom: `Endusers` (residential, public and
business), `Retail CSP` (Internet, Voice, TV, Security, ...),
`Wholesale CSP` (Active Network, L2Bitstream, L3Bitstream,...),
`Infrastructure CSP` (Passive Network, Trenches, ducts, fibre, cabinet
space).
