# customer-journey-fwaas-mockup.png

**Type:** UI wireframe/mockup, screen 12 of the customer journey flow.
**Source context:** `## Customer Journey screen flow`, step 12, the
selectable Firewall as a Service add-on with per-plan tiered usage
pricing.

Left nav tree shows `Firewall as a Service` selected, all `Add-ons
Subscription` items now reached. Right panel "Firewall as a Service"
("The service extends core DNS Security with additional capabilities:
Middle Box Security Function, Filtering of IP, Port and Protocol,
Malware Detection and Removal") with three plan columns, each listing a
per-actor base rate, a per-rule-per-actor rate, and three tiered
per-GB-usage rates: `Silver FWaaS` (€5/actor, selected), `Gold FWaaS`
(€4,5/actor), `Platinum FWaaS` (€4/actor) — all three share the same
€0,05 per-rule-per-actor rate but differ in per-GB tiers. Below, "Number
of Actors" set to `15` ("from 0 to 20", matching the Silver tier). `OK`
(highlighted/clicked) and `Cancel` buttons.
